# Manual de Usuario - Clasificador de Artrópodos

Bienvenido al manual oficial de usuario de la **Aplicación Móvil para la Detección y Clasificación Taxonómica de Artrópodos**, desarrollada en el marco del proyecto de investigación del **Centro de Investigación en Matemáticas (CIMAT)**.

---

## Propósito del Sistema

El objetivo principal de esta aplicación es ofrecer una herramienta de ciencia ciudadana e investigación biológica que permita a cualquier usuario identificar órdenes de artrópodos (insectos y arácnidos) en tiempo real a partir de fotografías tomadas en campo o cargadas desde la galería.

Combinando técnicas de **Visión por Computadora** e **Inteligencia Artificial (YOLOv8 + MobileNetV3)** con geolocalización satelital, la plataforma no solo clasifica las especies observadas, sino que permite construir un catálogo georreferenciado colaborativo.

---

## Características Principales

* **Identificación Automática:** Localización espacial de artrópodos mediante cajas delimitadoras (*bounding boxes*) y predicción de orden biológico con porcentaje de confianza.
* **Geolocalización GPS:** Registro de coordenadas exactas para cada observación en campo.
* **Ficha Taxonómica Completa:** Información biológica estructurada (Reino, Filo, Clase, Orden, Familia y Género).
* **Visor Interactivo en Pantalla Completa:** Inspección en alta resolución con zoom por pellizco o doble toque.
* **Mapa de Avistamientos Comunitario:** Exploración cartográfica interactiva con agrupación de marcadores (*clusters*).
* **Gestión por Roles:** Perfiles diferenciados entre **Observadores** (gestión de capturas personales) y **Administradores** (supervisión global y moderación).
